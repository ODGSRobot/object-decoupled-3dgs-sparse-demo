Overview

Expand structure-constrained support, not just the sample count

Sparse demonstrations leave large portions of a manipulation task unseen. Appearance-only augmentation can add images without adding task-relevant state transitions. We instead use object structure to define where virtual interaction may vary and screen every generated trajectory before it can affect policy training.

The loop begins with an initial policy trained on synchronized real top-view and wrist-view episodes. Foreground objects and background are reconstructed as separately controllable 3DGS assets, with rigid pose ranges or hinge parameters. The policy then performs closed-loop virtual rollouts under scene randomization. Only candidates that pass the implemented kinematic and geometric checks and manual review are written back for incremental training.

Method

Three coupled components

01

Training-only sequence regularization

The released policy architecture and inference path are retained. During training, first-order vector-field variation and second-order clean-action curvature are added to the original masked flow-matching objective. Both terms operate only on valid action dimensions.

Open the integration hook
02

Object-decoupled structural 3DGS

Objects and completed background are modeled separately in a common scene frame. Local object frames, rigid-pose ranges, hinge axes, centers, and angle limits expose task-relevant degrees of freedom while preserving view synthesis and object ownership.

Inspect structural-state code
03

Screened rollout and incremental update

Each candidate stores its seed, source episode, policy checkpoint, sampled scene state, check values, and review outcome. A trajectory enters the expanded set only when all automatic checks and the manual review pass. Rejected candidates remain in the provenance log.

Full environment

Install GR00T N1.7, 3DGRUT, Isaac Lab, and LeIsaac as separate pinned dependencies. The repository records the integration contract and resolved parameters without redistributing licensed upstream trees or model weights.

Record-level robot trials and rollout logs are not included in the public repository. Validation and plotting utilities accept explicit paths to author-local or independently collected records.

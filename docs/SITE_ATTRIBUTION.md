# Project-Page Attribution

The project page uses original HTML, CSS, and JavaScript written for this
repository. Its academic-paper information architecture was informed by:

* [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template),
  a responsive academic project-page template licensed under CC BY-SA 4.0.
* [Nerfies project page](https://github.com/nerfies/nerfies.github.io), which
  established a widely reused visual convention for computer-vision paper pages.

No template sample media, author assets, trackers, or third-party JavaScript
packages are included. The page is static, has no analytics, and can be served
directly from the repository's `docs/` directory.
